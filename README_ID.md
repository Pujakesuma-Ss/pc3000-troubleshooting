# PC3000-6E Troubleshooting Assistant v3

## Yang diperbarui
- Indeks pencarian isi teks bagian Troubleshooting by Trouble Code dan Troubleshooting by Symptoms dari Shop Manual PC3000E-6 yang diberikan pengguna.
- Pencarian kata/kode dan filter bagian.
- Menampilkan teks halaman sumber beserta nomor halaman PDF dan nomor halaman cetak bila terbaca.
- Form catatan pemeriksaan dan generator laporan TXT.

## Upload ke GitHub Pages lewat Android
1. Ekstrak ZIP.
2. Di repo GitHub, pilih Add file > Upload files.
3. Upload semua file dan folder di dalam ZIP ke root repo (index.html, app.js, style.css, manual_pages.json, README_ID.md).
4. Commit changes.
5. Buka URL GitHub Pages, lalu refresh.

## Batasan penting
Versi ini menyediakan teks manual yang dapat dicari; bukan berarti semua prosedur sudah ditulis ulang menjadi alur interaktif terstruktur. Diagram/gambar harus dilihat pada PDF asli. Selalu validasi halaman dan prosedur terhadap manual resmi, serial number, konfigurasi unit dan revisi terbaru. Tidak mengarang nilai standar yang tidak terbaca. Gunakan LOTOTO dan prosedur site.
